## Entry

`main.py` writes exactly one word to `/output/entry.txt`:

```text
micromancer
```

One word, 11 bytes, no trailing newline. A boss who micromanages like a
wizard casting spells: endless check-ins, approval for trivial things, and
status updates that are never enough. The first eight letters are the same
as "micromanager", so it reads instantly as a boss type — the "-mancer"
twist turns it into the joke.

## Run

```sh
python3 main.py
```

Stdlib only. No network, no randomness, no input files. The program writes
to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, otherwise `/output/entry.txt`.
